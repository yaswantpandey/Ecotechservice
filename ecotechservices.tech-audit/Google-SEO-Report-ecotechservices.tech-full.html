2. Audit Categories

2.1 Technical SEO

Score: 52/100

What Works

  • All active sitemap URLs return HTTP 200 without broken internal redirects
  • HSTS header actively deployed: Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
  • Comprehensive HTTP security headers (X-Frame-Options SAMEORIGIN, X-Content-Type-Options nosniff, Referrer-Policy, Permissions-Policy, COOP)
  • Brotli / Gzip compression active across all text mime types (saving ~81% transfer size)
  • Googlebot and Bingbot whitelisted and receiving full HTML payloads
  • IndexNow verification file (82568927e2e0467eac3f26e8e621ea0a.txt) reachable and returns 200 OK

Findings

TLS Handshake Missing Intermediate Certificate Authority Critical

The web server serves leaf certificate CN=ecotechservices.tech issued by Let's Encrypt YR2, but omits intermediate certificate YR2 from the TLS handshake. Standard Python, curl, and automated HTTP clients fail with 'SSLCertVerificationError: unable to get local issuer certificate'. While desktop browsers cache intermediates via AIA, headless crawlers and API fetchers fail immediately.

Recommendation: Install fullchain.pem (combining leaf + YR2 intermediate) into the hosting SSL configuration instead of only cert.pem.

Anti-Bot WAF Challenge Wall & Bot Discrimination Critical

InfinityFree shared hosting OpenResty reverse proxy intercepts non-whitelisted user agents with an 847-byte AES JavaScript challenge (aes.js / __test cookie) and returns HTTP 403 Forbidden to GPTBot, ClaudeBot, and PerplexityBot. YandexBot also receives HTTP 403.

Recommendation: Migrate from free shared hosting to standard shared hosting or VPS (e.g. Hostinger, Hetzner, DigitalOcean) with direct Apache/Nginx configuration and clean Cloudflare reverse proxy.

Missing 301 Canonical Redirects for HTTP and WWW Variants High

http://ecotechservices.tech, http://www.ecotechservices.tech, and https://www.ecotechservices.tech all respond with HTTP 200 OK rather than issuing a permanent 301 redirect to https://ecotechservices.tech. While rel=canonical is present, search engines still crawl duplicate host permutations.

Recommendation: Add mod_rewrite rules in public/.htaccess to redirect non-HTTPS and www requests to https://ecotechservices.tech with HTTP 301.

2.2 Content Quality & E-E-A-T

Score: 72/100

What Works

  • Transparent real-world business entity: physical studio in Lucknow, UP with postal code and GeoCoordinates
  • Direct verified contact channels: telephone (+917398301184), business email, WhatsApp
  • 8 comprehensive real-world portfolio case studies with technical specs
  • Comprehensive legal policies published (/terms, /privacy)
  • Local industry authority established for Lucknow engineering and digital solutions

Findings

/blog is Indexed in Sitemap but Contains Zero Articles High

The /blog endpoint is submitted in sitemap.xml with priority 0.8 and changefreq daily, but renders a thin 'No posts yet' panel. Crawlers prioritize this page daily only to encounter zero content value.

Recommendation: Publish 3 cornerstone technical articles on Web Security, Cloud Architecture, and Performance, or add 'noindex, follow' to /blog until articles are drafted.

High Template Redundancy Across 460 Programmatic Service Pages Medium

The 460 programmatic service x city pages share identical structural copy, FAQs, and value propositions with only token swaps ([Service], [City]). While helpful for long-tail discovery, Google's Helpful Content System evaluates thin doorway grids critically.

Recommendation: Enrich programmatic pages with city-specific metrics, regional project mentions, localized pricing estimates, and distinct testimonials.

2.3 On-Page SEO

Score: 64/100

What Works

  • Consistent single H1 per page across all core templates
  • Self-referencing rel=canonical implemented accurately across all 467 indexed URLs
  • Robots meta directives properly configured with max-image-preview:large, max-snippet:-1
  • 404 error pages correctly return noindex, follow

Findings

379 of 460 Programmatic Titles Exceed 60 Characters High

The template 'Best [Service] Company in [City] | Ecotech Services' generates titles up to 81 characters (average 66.4 characters). 82% of all page titles truncate in SERP snippets.

Recommendation: Update template to '[Service] in [City] | Ecotech' which caps maximum title length at 60 characters across all 460 combinations.

215 of 460 Meta Descriptions Exceed 160 Characters High

Programmatic meta descriptions average 160.4 characters with peaks at 175 characters. Search snippets truncate before completing the value proposition call-to-action.

Recommendation: Condense template description: 'Need [Service] in [City]? Ecotech Services builds fast, secure software with fixed pricing and ongoing support. Get a free quote.' (Caps at 155 chars).

2.4 Schema & Structured Data

  • Structured PostalAddress, GeoCoordinates, OpeningHours, and Social sameAs links
  • AggregateRating schema with ratingValue and reviewCount present
  • Zero schema syntax errors or malformed JSON blocks

Findings

Missing Service & FAQPage Schema on Programmatic Landing Pages Medium

The 460 city landing pages render FAQ accordions and specific service details, but omit FAQPage and Service JSON-LD schema, missing out on rich expandable SERP snippets.

Recommendation: Inject dynamic Service and FAQPage schema into app/views/seo_landing.php.

Missing BreadcrumbList Schema on Inner Pages Low

Inner service, project, and legal pages lack BreadcrumbList structured data, preventing Google from displaying hierarchical navigational breadcrumbs in SERPs.

Recommendation: Add BreadcrumbList JSON-LD to main layout reflecting hierarchy (Home > Services > [Service]).

What Works

  • Static compression active via Brotli and Gzip

2.6 AI Search Readiness (GEO)

Score: 28/100

What Works

  • robots.txt includes explicit Allow rules for GPTBot, ClaudeBot, PerplexityBot, and Applebot-Extended
  • Structured organization facts and entity definitions clearly expressed in homepage HTML

Findings

AI Search Bots Actively Blocked by WAF / Server Challenge Critical

Despite robots.txt permissions, GPTBot, ClaudeBot, and PerplexityBot receive HTTP 403 Forbidden, and Applebot-Extended receives an 847-byte JS challenge. Zero AI search engines can ingest or cite page content.

Recommendation: Migrate off InfinityFree WAF to hosting with transparent bot handling or configure Cloudflare WAF rules to allow verified AI crawlers.

/llms.txt Returns HTTP 404 Not Found on Production High

The llms.txt standard file is unrouted in public/index.php and .htaccess forwards it to a 404 error page. AI agents requesting /llms.txt cannot discover structured site capabilities.

Recommendation: Add rewrite exemption in public/.htaccess or add dedicated route in public/index.php serving public/llms.txt with text/plain content type.
