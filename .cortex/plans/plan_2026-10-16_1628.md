## Home page redesign: Three.js and motion

**What's there now:** `app/views/home.php` holds everything: the markup, the styles scoped under `.hm`, and a small script that reveals content as you scroll. It gets real data from `HomeController` (projects, services, testimonials, templates). The site has no build step: Tailwind loads from a CDN and deploys go straight over FTP. So the new libraries will load as **ES modules from a CDN** (jsDelivr) with pinned versions, and nothing gets installed.

**What we'll use**
- **Three.js r160**: an interactive 3D scene in the hero, built in WebGL.
- **GSAP 3 + ScrollTrigger**: animations tied to scrolling, such as pinned sections and timelines that play as you scroll.
- **Lenis**: smooth scrolling.
- I'm keeping the green-on-dark palette (#030712, #22c55e) and the existing header and footer from the layout. Only the home page changes.

### New sections (same real content, shown differently)
1. **Hero:** a full-screen Three.js scene behind the headline. It's a slowly rotating "network globe": a dot sphere made from GPU particles, with glowing arcs between nodes and a little bloom. The scene tilts with the mouse and drifts with scroll. The headline appears word by word, the call-to-action buttons have a magnetic hover, and a "scroll" cue sits at the bottom.
2. **Stats marquee:** a strip of the tech stack and key numbers that scrolls on an endless loop.
3. **What we build:** 6 capability cards that tilt in 3D and have a glow that follows the cursor. They fade in one after another as you scroll.
4. **How a project runs:** a pinned section that scrolls sideways through the 5 stages. A progress line draws itself and the stage numbers count up.
5. **Live work:** real project cards scroll sideways with a parallax image effect, plus your existing skeleton loaders. The project list is in a grid on mobile.
6. **Ways to work with us** and **Internships:** cards with gradient borders that animate, kept in the current content structure.
7. **Testimonials** (the controller already loads them; the current page doesn't show them): a slider that fades between quotes.
8. **Final call to action:** a big headline that fills with colour as you scroll past.

### Performance and accessibility
- The 3D scene loads lazily after first paint, caps pixel ratio at 1.5 and fewer particles on mobile. It pauses when off-screen or when the tab is hidden.
- If WebGL isn't available, a static CSS gradient shows instead.
- If the visitor has reduced motion turned on in their system settings, the page skips all animation and smooth scrolling, and the 3D scene renders as a still frame. All content stays in the HTML, so SEO and readers without JS are unaffected.
- All database output stays escaped with `Security::e()`.
