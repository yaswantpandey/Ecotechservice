### Security decisions

- **Resumes stored outside the webroot** at `ROOT_PATH/storage/resumes/`, randomised filenames, plus a deny-all `.htaccess` there and `storage` added to the blocked-dirs rule in `public/.htaccess`. Served only through an authenticated controller via `readfile()` + `Content-Disposition`.
- `Security::uploadDocument()`: `finfo` MIME check against PDF/DOC/DOCX, extension whitelist, 2 MB cap, explicit `UPLOAD_ERR_*` messages.
- Intern session is `$_SESSION['intern_id']`, fully independent of `admin_id`. **Intern logout unsets only intern keys** instead of `session_destroy()`, so it can't kill a concurrent admin session. `session_regenerate_id(true)` on login.
- Login throttling mirroring your admin pattern (5 attempts / 5 min), generic failure messages.
- Ownership enforced on every intern read: resume, application detail and offer letter are all scoped `WHERE intern_id = :session_intern`.
- Admin status updates and deletes use **POST + CSRF** — deliberately stricter than the existing GET deletes.
- Server-side validation on every field, `Security::e()` on all output, prepared statements throughout.
